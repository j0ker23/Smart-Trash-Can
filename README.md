
# Smart Trashcan

## Overview
A replica of a modern smart mini trash can built using an ESP32 MakerBoard and other sensors.

## Features
- Automatic lid opening using an ultrasonic sensor and servo motor.
- Trash capacity detection using an internal ultrasonic sensor.
- LED ring that changes color based on trash capacity.

## Hardware
- ESP32 MakerBoard (1)
- Ultrasonic distance sensors (2)
- Servo motor (1)
- 16-pixel NeoPixel LED ring (1)

## How to Run
- Make sure to connect the hardware according to the circuit design.
- Upload the code to the ESP32.
